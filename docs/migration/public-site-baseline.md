# Línea base del sitio público heredado

## Tecnología observada

- HTML estático de una sola página.
- Bootstrap 3.3.7 servido desde CDN.
- jQuery 3.3.1 servido desde CDN.
- Google Fonts: Lato y Montserrat.
- CSS y JavaScript propios en `app/css` y `app/js`.
- Google Analytics configurado en la página heredada.

## Contenido visible identificado

- Navegación fija y menús por anclas.
- Carrusel fotográfico.
- Presentación y objetivo general de OLCOMEP.
- Anuncios, promoción e inscripción de la edición 2026.
- Descargas de manual, temario, reglamento y protocolo.
- Cuadernillos organizados por año, estudiante y docente.
- Contacto y enlaces externos.

## Lectura de diseño

Interfaz educativa institucional dirigida a estudiantes, familias y personal docente, orientada a consultar información y descargar recursos oficiales, con un tono cercano y formal.

- Variación: 3/10.
- Movimiento: 2/10.
- Densidad: 6/10.

## Restricciones de migración

- Mantener nombres y rutas de documentos mientras existan enlaces externos hacia ellos.
- No eliminar contenido histórico sin una decisión explícita.
- Conservar logotipos, fotografías y colores reconocibles; cualquier ajuste deberá mejorar legibilidad o accesibilidad.
- Mantener el sitio heredado disponible hasta completar la comparación funcional.
